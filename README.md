# For Lea, Tsonggi ♡

A little friendship website built with React + Vite. It has six screens, responsive layouts, a friendship-verification gag, reasons cards, a letter, a house invitation, and seven clickable secrets.


## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Framework preset: **Vite** (Vercel usually detects this automatically).
4. Build command: `npm run build`
5. Output directory: `dist`
6. Click **Deploy**.

No environment variables are required. Sound is off by default and uses tiny synthesized browser chimes only after enabling it.
